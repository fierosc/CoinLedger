Exchange Rates

EVOLVED PWI
Drop % figures on this site are pulled from pwdatabase, which lists retail (official server) drop rates. PWI's actual drop process happens in three separate stages. First, a gate based on the level gap between you and the monster decides whether anything drops at all from that kill. Second, if that passes, the server rolls how many items drop, usually 0 to 3, though bosses can repeat this roll several times and drop far more. Third, the server rolls which specific item fills each of those drop slots, chosen from everything on that monster's loot table. That third roll is the percentage pwdatabase and this site actually show. This server runs a 2x drop rate, but that multiplier only touches part of this chain rather than the final number directly. It can't be applied by simply doubling the listed percentage. Actual in-game odds run better than what's shown here, though not a clean 2x.
